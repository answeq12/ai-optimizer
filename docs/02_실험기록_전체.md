# 실험 기록 전체 (실험 노트)

모든 실험을 시간순으로 한곳에 모은 기록이다. **실험을 하나 끝낼 때마다 맨 아래에 항목을 추가한다.**
수치 원본은 자동 생성 표(`results/all_runs.md` 등)에 있고, 이 문서는 "무엇을 왜 했고 무엇을 알았나"를 적는다.
현재 상태 요약은 `01_인수인계_현재상태.md`, 측정 규칙은 `PROTOCOL.md`.

- 모델: CLIP ViT-B/16 이미지 인코더 (open_clip, openai 가중치), ONNX opset 17, 배치 1
- 장비: PC00 (i9-14900KF, WSL Ubuntu 22.04), ORT 1.23.2 CPU 4스레드 / Hailo DFC 5.4.0 (CPU) → Hailo-10H
- CIFAR = CIFAR-100 train에서 분리한 검증 10,000장 top-1 (표준오차 ±0.46%p). Hailo 에뮬레이터는 같은 이미지의 앞 2,000 또는 5,000장
- COCO R@1 = COCO val2017 자체 분할 select 2,405장, 텍스트→이미지 검색 (10/13부터 주 평가)
- 구성 이름은 `01_인수인계_현재상태.md` 3장과 `results/all_runs.md`의 이름을 그대로 쓴다

## 구성 이름 읽는 법

| 접두어 | 뜻 |
|---|---|
| A0 / A1 / A2 | FP32 / 동적 INT8 / 정적 INT8 (ORT 기본 대상) |
| A2m | 정적 INT8, 가중치 MatMul 49개만 양자화 |
| P-* , AB-* | A2 위의 회복 탐침, 캘리브레이션 A/B (A2 붕괴로 무효) |
| AB2-* | A2m 위의 캘리브레이션 A/B |
| S-<층> / S-b<N>-fc2 / S-c<블록들>-fc2 | 레이어 민감도: 그 층을 FP32로 남김 (c67 = 블록 6·7) |
| -pc / -qop / -attn | per-channel / QOperator 형식 / 어텐션 MatMul까지 INT8 |
| SPL-b<블록>-k<개수> | fc2 입력 이상치 채널 k개를 FP32 작은 행렬곱으로 분리 |
| I4-* | 가중치 전용 INT4 (MatMulNBits) |
| H-* | Hailo 에뮬레이터. H-FP, H-official(공식 설정), H-fc2b7 / b67 / b567 (그 블록 fc2를 a16_w16) |

### E36. 텍스트 인코더 뒤쪽 4블록도 함께 학습 (10/21 사전 등록)

### E39. 양자화 보정 학습 (QAT + FP32 증류, 원본 가중치) — 10/21 사전 등록
- 목적: 양자화 손실(SPL −0.96%p) 축소. 과제는 바꾸지 않음: 정답 = 같은 모델의 FP32 출력, 캡션·라벨 안 씀(학습 사진은 train2017 앞 10,000장, 라벨 없이)
- 방법: 배포 INT8(SPL) 모델에서 블록 7 출력(블록 0~7 실제 양자화 오차 포함)을 ORT 로 저장 → 블록 8~11+ln_post+proj 를 INT8 흉내(가중치 채널별 int8, 활성 텐서별 uint8 MinMax, 캘리브 s0 범위 고정, STE) 상태로 FP32 출력과의 코사인 거리 최소화. AdamW lr 1e-5, 배치 64, 3에폭, 시드 0, 보류 500장으로 코사인 확인
- 이후 FP32 가중치를 원래와 같은 SPL 처방으로 ORT 양자화(QAT-SPL) → select·CIFAR val
- 채택 규칙: select 에서 (QAT-SPL − SPL) R@1 짝지은 차이의 CI 하한 > 0 이고 CIFAR val 이 SPL 대비 −0.5%p 이내면 "양자화 손실 축소 성공". 아니면 실패로 기록. 최종 구성 결정은 학술부 답 이후 한 번에(E34)
- 적응 모델(da)에도 같은 코드가 있으나, 학술부 답이 "추가 학습 허용"일 때만 돌린다
