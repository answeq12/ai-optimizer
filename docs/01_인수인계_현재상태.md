## 2. 실험 실행: 작업 대기소

- 사용자가 `00_작업대기소_켜기.bat`을 켜두면 `jobs/*.sh`를 이름 순서대로 하나씩 WSL에서 실행 (작업 폴더 = 프로젝트 루트)
- 작업 넣기: `jobs/YYYYMMDD_HHMM_<순서>_<이름>.sh`. 파일럿 환경이 필요하면 첫 줄에 `source ~/venvs/halio/bin/activate`, DFC는 `bash dfc/setup_and_smoke.sh ...` (CPU 고정 시 `export CUDA_VISIBLE_DEVICES=''` — GPU 실패 후 CPU 재시도로 시간 2배 되는 것 방지)
- 상태: `jobs/running.txt`(실행 중), `jobs/.heartbeat`(epoch초, 15초마다 — 오래됐으면 대기소 꺼짐), `jobs/logs/<이름>.log`(마지막 줄 `rc=`), 끝난 작업 `jobs/done/`. 멈추기: `jobs/STOP`
- **주의**: 작업 스크립트에 `set -e`가 없으면 중간 실패해도 `rc=0`이 찍힌다. 로그에서 `✘|실패|Error`를 꼭 확인
- **속도 측정 작업은 사용자에게 "다른 작업 없음"을 확인받은 뒤에만** 넣는다. 정확도만 재는 작업은 언제든 가능
