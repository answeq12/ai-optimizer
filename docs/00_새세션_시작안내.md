# 새 세션 시작 안내 (사람·Claude 공통)

이 프로젝트를 처음 열거나 새 Claude 세션에서 이어서 작업할 때 **이 문서부터** 읽는다.

## 1. 이 프로젝트는

2026 모바일공학전공 하반기 공모전 트랙 2 자유주제. CLIP ViT-B/16 이미지 인코더를 INT8로 양자화하면서
정확도 손실을 FP32 수준으로 막는 구성을 찾고(PC, ONNX Runtime), 같은 전략을 Hailo-10H로 옮긴다.
주 평가는 COCO 텍스트→이미지 검색(R@1), 보조는 CIFAR-100 zero-shot.

## 3. 작업을 끝낼 때 갱신할 것

1. `02_실험기록_전체.md` 맨 아래에 실험 항목(E번호) 추가
2. `01_인수인계_현재상태.md` 의 본문(결과 표, 다음 할 일)을 고치고 "갱신 기록"에 한 줄
3. 규칙을 바꿨으면 `PROTOCOL.md` 에 날짜와 이유를 적는다
4. 노션 작업 관리·실험 기록에 같은 내용 반영

## 4. 폴더 구조

```
halio project/
├─ 00_작업대기소_켜기.bat     실험 자동 실행 창. 켜 두면 jobs/*.sh 를 하나씩 WSL에서 실행
├─ 98_폴더정리.bat           흩어진 파일 정리 (옮기기만, 삭제 없음) → tools/organize.sh
├─ 99_불필요파일_삭제.bat     삭제 후보를 보여 주고 확인 후 휴지통으로 → tools/delete_list.txt
├─ README.md                 설치·실행 방법
├─ 실행파일_bat/              더블클릭 실행 파일 (1-x 설치, 2-x ORT 실험, 3-x Hailo 컴파일)
├─ docs/                     문서 (이 파일, 인수인계, 실험 기록, 프로토콜, 보고서 표현 규칙, 팀 공유 PDF)
├─ src/                      ORT 실험 코드 (common.py 가 경로·전처리·CSV 스키마의 단일 소스)
├─ dfc/                      Hailo DFC 코드 (smoke_test.py, coco_ret_eval.py, compare_preds.py)
├─ tests/                    셀프테스트용 가짜 데이터
├─ splits/                   검증셋·캘리브·COCO 검색 분할 목록 (바꾸지 않는다)
├─ results/                  결과 표·CSV·이미지별 예측 (results/README.md)
├─ logs/                     실행 로그, DFC 로그, 프로파일 (logs/README.md)
├─ jobs/                     작업 대기소: 대기 *.sh, done/ 끝난 작업, logs/ 출력 (jobs/README.md)
├─ installers/               Hailo DFC·Model Zoo 휠 (계정으로 받은 파일, 재배포 금지)
├─ tools/                    폴더 정리·삭제 스크립트
├─ _archive/                 예전 코드 백업(*.bak_*)·예전 bat. 실행에 쓰지 않음
├─ *.sh                      실행 순서 스크립트 (setup_and_run.sh 가 입구, job_runner.sh 는 대기소)
└─ requirements*.txt, wsl_distro.txt
```

- 큰 파일(데이터·ONNX·HAR·HEF)은 `D:\halio_data` (WSL: `/mnt/d/halio_data`). 이 폴더에는 없다
- 루트의 `.sh` 파일들은 서로 상대 경로로 부르므로 **옮기지 않는다**

## 5. Claude 세션용 메모

- Cowork 셸(device_bash)은 WSL이 아니다. 파일 읽기·쓰기만 되고 D 드라이브는 안 보인다. 실험은 `jobs/` 에 `.sh` 를 넣어 작업 대기소로 돌린다 (방법: `jobs/README.md`)
- 테스트셋(CIFAR test)과 COCO-confirm은 최종 구성 동결 전에 열지 않는다
- 속도 측정은 사용자에게 "다른 작업 없음"을 확인받은 뒤에만
- 로그는 크다. 필요한 줄만 grep 한다 (COCO 진행 표시 줄이 많음)
- 사용자는 한국어 설명을 선호한다
- 이 폴더 밖의 다른 팀 폴더(track2, mokerton 등)는 쓰지 않는다
